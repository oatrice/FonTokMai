# UX/UI Interaction Guidelines: Map & Location Navigation

บันทึกแนวทางการออกแบบประสบการณ์ผู้ใช้งาน (User Experience) สำหรับแอป FonMaYang ในส่วนของการจัดการพิกัดและการนำทางบนแผนที่หลัก

## 1. Contextual Map Transition (การเชื่อมต่อ My Places -> Main Map)
**ปัญหา:** ผู้ใช้ต้องการดูสภาพอากาศของพิกัดที่เซฟไว้เมื่อกดเลือกจากหน้ารายการ
**แนวทางแก้ไข (UX Pattern: Fly-to & Focus):**
*   **Action:** เมื่อกดเลือกการ์ดสถานที่ (เช่น "บ้าน") จากหน้ารายการ (Step 1)
*   **Animation:** หน้ารายการจะถูกซ่อนลง (Slide down/Fade) และแผนที่หลัก (Step 2) จะใช้คำสั่ง `flyTo` หรือ `easeTo` ซูมพุ่งไปยังพิกัดนั้นอย่างนุ่มนวล
*   **Feedback:** มี Marker ปักลงตรงกลางพิกัด พร้อมกับ Bottom Sheet ที่แสดงผลการพยากรณ์อากาศของจุดนั้นเด้งขึ้นมาทันที

## 2. Overview Mode (การดูพิกัดที่เซฟไว้ทั้งหมดบนแผนที่)
**ปัญหา:** ผู้ใช้มีหลายพิกัด (บ้าน, ที่ทำงาน, โรงเรียน) และต้องการประเมินสถานการณ์ฝนภาพรวม
**แนวทางแก้ไข (UX Pattern: Zoom to Bounds):**
*   **UI Element:** เพิ่มปุ่ม Floating Action Button (FAB) บนหน้าแผนที่ เช่น ไอคอน `หมุดหลายอัน` หรือ `กรอบโฟกัส`
*   **Action:** เมื่อกดปุ่ม ระบบจะคำนวณ Bounding Box ของพิกัดที่บันทึกไว้ทั้งหมด
*   **Animation:** แผนที่จะซูมออก (Zoom out) และจัดตำแหน่งให้อยู่ตรงกลาง เพื่อให้มองเห็นทุก Marker บนหน้าจอเดียว
*   **Benefit:** ช่วยให้ประเมินได้ทันทีว่ากลุ่มฝนกำลังเคลื่อนตัวไปโดนพิกัดไหนบ้าง โดยไม่ต้องไล่กดดูทีละจุด

## 3. Seamless Location Browsing (การเลื่อนดูพิกัดโดยไม่ต้องย้อนกลับไปหน้าแรก)
**ปัญหา:** การกด Back กลับไปหน้าแรกเพื่อเปลี่ยนพิกัดทำให้เสียเวลาและขัดจังหวะการดูแผนที่
**แนวทางแก้ไข (UX Pattern: Swipeable Carousel & Background Sync):**
*   **Approach A: Swipeable Bottom Sheet**
    *   สร้าง Bottom Sheet ให้เป็นรูปแบบ Carousel (มีจุด Page Indicator `• • •` แสดงจำนวนพิกัด)
    *   เมื่อผู้ใช้ปัดซ้าย/ขวา (Swipe) ที่การ์ด แผนที่ด้านหลังจะทำการ `flyTo` ไปยังพิกัดถัดไปโดยอัตโนมัติ (Background Sync)
*   **Approach B: Header Dropdown**
    *   เพิ่มปุ่ม Dropdown ที่ชื่อสถานที่บน Top Navigation Bar (เช่น `📍 บ้าน ▾`)
    *   เมื่อกด จะมีเมนูคลี่ลงมาให้เลือกพิกัดอื่นที่บันทึกไว้ได้ทันที

## 🎯 Architectural Shift Summary
*   กำหนดให้ **หน้าแผนที่เรดาร์ (Main Map)** เป็น **หน้าจอหลัก (Home Screen)** ของแอปพลิเคชัน
*   หน้าต่างการค้นหาหรือจัดการพิกัด (Location Setup) ควรมีสถานะเป็น **Overlay / Modal / Settings** ที่เรียกใช้งานแบบ Pop-up และสามารถปิดกลับไปหน้าแผนที่หลักได้ง่าย เพื่อรักษา Context การมองเห็นสภาพอากาศอย่างต่อเนื่อง
