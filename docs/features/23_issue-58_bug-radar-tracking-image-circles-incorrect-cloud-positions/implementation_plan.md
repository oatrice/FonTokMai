# แผนการแก้ไขปัญหาวงกลมและลูกศรบนภาพ Radar Tracking ไม่ตรงกับกลุ่มฝน

## ปัญหาที่พบ (Problem)
ผู้ใช้รายงานว่าวงกลมและลูกศรในภาพที่ได้จาก `generate_radar_tracking_image` วางตำแหน่งไม่ตรงกับกลุ่มฝน และคาดว่าอาจจะเกิดจากบั๊กในการคำนวณ Crop และ Upscale (Coordinate mapping)

จากการทดสอบและวิเคราะห์โค้ดอย่างละเอียด (ผ่านสคริปต์ `test_tracking_image.py` และ `tests/analyze_image.py`) พบว่า **สมการการทำ Coordinate mapping นั้นถูกต้อง 100%** (การนำพิกัดคูณด้วย `scale` หลังจากลบ offset สามารถวางตำแหน่งวงกลมและลูกศรได้แม่นยำระดับพิกเซล)

**สาเหตุที่แท้จริง (Root Cause):**
บั๊กเกิดจากอัลกอริทึม **การจัดกลุ่มเมฆฝน (Clustering)** ในฟังก์ชัน `find_approaching_clouds`
อัลกอริทึมปัจจุบันทำงานแบบ Single-pass:
```python
# โค้ดปัจจุบัน
for j, c2 in enumerate(candidates):
    if math.sqrt((c[0] - c2[0]) ** 2 + (c[1] - c2[1]) ** 2) < cluster_dist:
        group.append(c2)
```
เนื่องจากมันสแกนพิกเซลจากซ้ายบนไปขวาล่าง พิกเซลแรกที่มันเจอจะเป็น "ขอบซ้ายบน" ของกลุ่มฝน จากนั้นมันจะกวาดเอาเฉพาะพิกเซลที่อยู่ห่างจาก "ขอบ" นี้ไม่เกิน `cluster_dist` (20 px) ทำให้เมฆก้อนใหญ่ๆ ถูกหั่นเป็นหลายๆ ก้อนเล็กๆ และจุดศูนย์กลาง (Centroid) ของแต่ละกลุ่มไปกระจุกอยู่บริเวณ "ขอบ" ของกลุ่มฝน แทนที่จะเป็น "ตรงกลาง" ของกลุ่มฝนจริงๆ

ส่งผลให้เมื่อนำ `cx, cy` ไปวาดวงกลม วงกลมจึงดูเหมือนวางผิดตำแหน่ง (เบี้ยวไปอยู่ขอบเมฆ หรือไม่อยู่ตรงกลางก้อน)

> [!NOTE]
> ผู้ใช้สังเกตเห็นอาการเบี้ยวนี้ และเข้าใจผิดว่าเป็นเรื่องของการ Crop/Upscale Image แต่แท้จริงแล้วพิกัดที่ถูกส่งมาให้วาดนั้น "ผิด" มาตั้งแต่ขั้นตอนการหาจุดศูนย์กลางของเมฆแล้ว

## Proposed Changes (แนวทางการแก้ไข)

### 1. แก้ไขอัลกอริทึม Clustering ให้เป็นแบบ BFS (Breadth-First Search)

#### [MODIFY] `app/services/tmd_radar_processor.py`
ในฟังก์ชัน `find_approaching_clouds` จะทำการปรับ logic ในการจัดกลุ่มพิกเซล `candidates` โดยเปลี่ยนจากการเทียบระยะห่างแค่กับพิกเซลแรก (`c`) มาเป็นการทำ BFS เพื่อเชื่อมต่อพิกเซลที่อยู่ติดกันทั้งหมดเป็นกลุ่มก้อนเดียวกัน

**โค้ดที่จะแก้ไข:**
```python
        clusters = []
        used = [False] * len(candidates)
        for i, c in enumerate(candidates):
            if used[i]:
                continue
            group = [c]
            used[i] = True
            
            # ใช้ BFS เพื่อควบรวมพิกเซลทั้งหมดที่เป็นก้อนเดียวกัน (Connected Components)
            queue = [c]
            while queue:
                curr = queue.pop(0)
                for j, c2 in enumerate(candidates):
                    if not used[j]:
                        # ถ้าระยะห่างจากพิกเซลปัจจุบันใน queue < cluster_dist ให้รวบเข้ากลุ่ม
                        if math.sqrt((curr[0] - c2[0]) ** 2 + (curr[1] - c2[1]) ** 2) < cluster_dist:
                            group.append(c2)
                            used[j] = True
                            queue.append(c2)

            # คำนวณจุดศูนย์กลางเหมือนเดิม
            total_w = sum(g[4] for g in group)
            cx = int(sum(g[0] * g[4] for g in group) / total_w)
            cy = int(sum(g[1] * g[4] for g in group) / total_w)
            # ...
```

การปรับปรุงนี้จะทำให้เมฆก้อนใหญ่ถูกรวบเป็น `group` เดียวกันทั้งหมด และ `cx, cy` ที่ได้จะเป็นจุดศูนย์กลางมวล (Center of mass) ของกลุ่มฝนก้อนนั้นอย่างแท้จริง ทำให้วงกลมถูกวาดตรงกลางก้อนฝนพอดี
