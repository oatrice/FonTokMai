# คู่มือทดสอบระบบ Xweather และระบบแจ้งเตือนขั้นสูง (แบบเข้าใจง่าย)

ไฟล์นี้สรุปวิธีทดสอบฟีเจอร์ที่พัฒนาใน Batch F ทั้ง 2 กรณีครับ (คุณสามารถเปิดอ่าน Log ของ Backend ควบคู่ไปด้วยเพื่อดูการสลับ Service)

---

## 🌩️ กรณีที่ 1: ระบบทำงานปกติ (ได้ข้อความฝน + ข้อความภัยขั้นสูงจาก Xweather)

**วิธีทดสอบ:**
1. พิมพ์คำสั่ง `/devmock rain` ใน Telegram Bot เพื่อเปิดโหมดจำลองพายุ
2. รันคำสั่งยิงแจ้งเตือนผ่าน Terminal ของคุณ:
   ```bash
   curl -X POST http://localhost:8001/api/v1/cron/check-rain -H "X-Cron-Secret: default_secret_for_local_testing"
   ```
3. **ผลลัพธ์ที่คาดหวังใน Telegram:**
   - ได้รับ **กล่องแรก** แจ้งเตือนฝนตกหนัก (สังเกตเครดิตด้านล่างจะเป็น `Xweather`)
   - ได้รับ **กล่องสอง** "🚨 ข้อมูลเตือนภัยขั้นสูงรอบตัวคุณ" (มีแจ้งเตือนพายุ ฟ้าผ่า)

---

## 🛑 กรณีที่ 2: จำลองว่า Xweather ล่ม หรือใส่ API Key ผิด (ระบบเปิด Circuit Breaker และสลับไปใช้ Tomorrow.io)

**วิธีทดสอบ:**
1. พิมพ์คำสั่ง `/devmock off` ใน Telegram Bot เพื่อปิดโหมดจำลอง (ให้ระบบทำงานแบบยิง API ออกโลกภายนอกจริงๆ)
2. แก้ไขไฟล์ `.env` ตรง `XWEATHER_CLIENT_SECRET` ให้เป็นอะไรก็ได้ที่ผิด (เช่น เติม `xxx` ต่อท้าย)
3. **สำคัญ:** ต้อง **Restart ตัว Backend Server (FastAPI/Uvicorn)** เพื่อให้ระบบอ่านค่า `.env` ใหม่
4. รันคำสั่งยิงแจ้งเตือนผ่าน Terminal ของคุณ:
   ```bash
   curl -X POST http://localhost:8001/api/v1/cron/check-rain -H "X-Cron-Secret: default_secret_for_local_testing"
   ```
5. **ผลลัพธ์ที่คาดหวัง:**
   - **ในหน้าจอ Console Backend:** คุณจะเห็น Log สีแดงแจ้งว่า 
     `Xweather rate limit/auth hit: 401 ...` 
     ตามด้วย `Falling back to Tomorrow.io`
   - **ใน Telegram:** 
     - **ถ้าหากพิกัดที่คุณอยู่ ณ ขณะนั้นมีฝนตกจริงๆ:** คุณจะได้รับกล่องแจ้งเตือนที่มีเครดิตว่า `Tomorrow.io` โดยที่ **จะไม่มีกล่องที่สองโผล่มา**
     - **ถ้าหากพิกัดที่คุณอยู่ไม่ได้มีฝน:** คุณจะไม่ได้รับข้อความอะไรเลยใน Telegram (ซึ่งเป็นเรื่องปกติ เพราะระบบจะไม่กวนผู้ใช้ถ้าฝนไม่ตก) แต่ให้ดูที่ Log เพื่อยืนยันว่าระบบสลับไปใช้ Tomorrow.io แล้วจริงๆ
