# FonMaYang Frontend 🌧️🎨

Next.js 15 App Router Frontend for FonMaYang Real-Time Dashboard and Rain Radar Tracker.

## Stack & Architecture
- **Framework:** Next.js 15 (App Router) + TypeScript
- **Styling:** Vanilla CSS + Tailwind CSS + Glassmorphism
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Real-Time Data:** EventSource (SSE) Integration (`useEventStream`)

## Development Setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Running Tests

```bash
# Unit Tests (Jest + React Testing Library)
npm run test

# End-to-End Tests (Playwright)
npm run test:e2e
```
