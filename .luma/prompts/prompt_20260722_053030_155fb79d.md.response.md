# Manual Verification Guide

## Step 1: Prepare Environment & Dependencies
1. Activate backend virtual environment:
   ```bash
   cd backend
   source .venv/bin/activate
   ```
2. Verify required dependencies are installed:
   ```bash
   uv pip list | grep -E "google-cloud-billing|boto3"
   ```
   *(Or using python directly: `python -c "import boto3, google.cloud.billing; print('Installed!')"`)**

## Step 2: Run Automated Unit Tests
1. Execute pytest for the billing service:
   ```bash
   pytest tests/test_billing_service.py -v
   ```
2. **Expected Result**: All 3 unit tests (`test_fetch_gcp_costs_success`, `test_fetch_aws_costs_success`, `test_aggregate_costs`) pass cleanly.

## Step 3: Verify Cost Aggregation Execution via Python CLI
1. Execute python interactive one-liner to verify `BillingService.aggregate_costs()`:
   ```bash
   python -c "
   import asyncio
   from app.services.billing_service import BillingService

   async def main():
       service = BillingService()
       agg = await service.aggregate_costs()
       print(f'Baseline: {agg.baseline_cost}, Variable: {agg.variable_cost}, Total: {agg.total_cost}')

   asyncio.run(main())
   "
   ```
2. **Expected Result**: Output prints the aggregated costs:
   ```text
   Baseline: 250.0, Variable: 145.0, Total: 395.0
   ```
