# Manual Verification Guide

## Step 1: Verify the radar pin uses static image coordinates

Run the focused radar E2E test:

```bash
PYTHONPATH=/private/tmp/codex_hermesdeps:backend python3 -m pytest backend/tests/test_tmd_radar_e2e.py -q
```

Expected Result:
- The test file passes.
- The regression test confirms `WeatherManager` calls `latlng_to_pixel(..., is_loop=False)` for cached static radar frames.

## Step 2: Manually generate a radar prediction for a known coordinate

Use a coordinate covered by `kkn240`, such as Nong Khai:

```bash
PYTHONPATH=/private/tmp/codex_hermesdeps:backend python3 - <<'PY'
from app.services.tmd_radar_processor import TMDRadarProcessor

lat, lng = 17.8785, 102.7420
processor = TMDRadarProcessor("kkn240")
print("loop:", processor.latlng_to_pixel(lat, lng, is_loop=True))
print("static:", processor.latlng_to_pixel(lat, lng, is_loop=False))
PY
```

Expected Result:
- The loop and static coordinates differ.
- Production static-frame rendering should use the static coordinate.
- For Nong Khai on current config, the static coordinate should be around `(425, 158)`.

## Step 3: Verify `apply_cloudrun_config.sh` loads config correctly

Run the script in dry-review mode by printing the config it will use before applying it:

```bash
bash -n backend/deploy/apply_cloudrun_config.sh
```

Expected Result:
- The shell syntax check exits successfully.

Then inspect the config values:

```bash
sed -n '1,120p' backend/deploy/cloudrun.env
```

Expected Result:
- Non-secret Cloud Run settings are present.
- `CLOUD_RUN_ALLOW_UNAUTHENTICATED=true` is present.
- CPU throttling is disabled with `CLOUD_RUN_NO_CPU_THROTTLING=true`.

## Step 4: Verify config-only Cloud Run command behavior

Only run this against the intended GCP project.

```bash
cd backend
gcloud config get-value project
./deploy/apply_cloudrun_config.sh
gcloud run services get-iam-policy fontokmai-api \
  --region asia-southeast1 \
  --format='table(bindings.role,bindings.members)'
```

Expected Result:
- The active project is the expected project.
- `gcloud run services update fontokmai-api` completes successfully.
- The service retains the intended region, memory, CPU, timeout, min/max instances, concurrency, CPU boost, and no CPU throttling settings.
- If `CLOUD_RUN_ALLOW_UNAUTHENTICATED=true`, the IAM policy includes `allUsers` with `roles/run.invoker`.
- The script does not pass `--allow-unauthenticated` to `gcloud run services update`; public access is handled through IAM policy binding.
