- Step 1: Execute the script locally in your terminal by running: `./backend/scripts/setup_cloudrun_alerts.sh`. You should see success messages for each policy creation.
- Step 2: Open your web browser and log in to the Google Cloud Console.
- Step 3: Navigate to **Monitoring -> Alerting -> Policies**.
- Expected Result: You should see 4 newly created Alert Policies for the `fonmayang` service (Memory Utilization > 80%, Latency P95 > 5000ms, Error Rate > 5%, Instance Count == 0). You can click into each one to verify that the metrics, thresholds, and durations match the script definitions.
